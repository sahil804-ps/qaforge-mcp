local · stdio

Run it on your machine

Full cross-browser diffing (Chromium, Firefox, WebKit) and k6 load testing. One process per user.

pip install qaforge-mcp playwright install chromium firefox webkit
claude mcp add --scope user qaforge \ -e ANTHROPIC_API_KEY=your-key -- python -m qaforge_mcp

uses your own ANTHROPIC_API_KEY env var

hosted · connector

Add the shared connector

Nothing to install. Add it once in Claude's connector settings and bring your own key at request time.

URL https://qaforge-mcp.onrender.com/mcp
Header X-Anthropic-Api-Key: your-key

your key is sent per-request, never stored on the server
